## *Herramienta de animación online*

**Implementación web del software Flipnote Studio del sistema Nintendo DS y 3DS a lenguaje de marcado nativo**

Una recreación del programa dedicado a animación pero en formato de aplicación web para crear animaciones, almacenarlas, clasificarlas y buscarlas entre varios usuarios de la plataforma. 

# INSTRUCCIONES

Para la instalación local en una máquina de este código se necesita descargar el contenido del respositorio en formato zip o clonar la rama actual con ```git clone https://github.com/ChinChainis/Proyecto-Hopblog.git```

Una vez con la estructura de carpetas desplegada en su dispositivo de abre un intérprete de comandos y se ejecuta ```npm start``` para que la carpeta de dependencias se encarge de instalar los módulos necesarios para ejecutar el archivo del [servidor](https://github.com/ChinChainis/Proyecto-Hopblog/blob/main/server.js).

Hay que comprobar las variables de entorno que se empleen, dado que para este proyecto usa una alojada en Clever Cloud privada, aconsejable crear archivo .env con variables de ```MYSQL_HOST, MYSQL_USER, MYSQL_PASSWORD y MYSQL_DB``` correspondientes.
